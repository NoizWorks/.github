## MediaLatch

A browser extension for saving selected images, videos and GIFs, organizing files and following downloads. Version 3.0.7 saves locally or to Google Drive or Yandex Disk.

[Install from Chrome Web Store](https://chromewebstore.google.com/detail/medialatch/cimghidldpjhhhngdhigddjfpcofhbmh) · [MediaLatch website](https://noizworks.is-a.dev/medialatch/) · [Downloads and documentation](https://github.com/NoizWorks/MediaLatch) · [Releases](https://github.com/NoizWorks/MediaLatch/releases) · [MediaLatch privacy](https://noizworks.is-a.dev/privacy.html#medialatch)

MEGA uploads and Telegram posting are in development. See the release notes for features in your installed version.
